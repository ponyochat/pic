# pic

이미지 링크용 공개 저장소입니다. 기존 홈페이지 저장소와는 별도로 관리합니다.

## 이미지 올리기

1. 저장소 첫 화면에서 **Add file → Upload files**를 선택합니다.
2. 이미지를 끌어다 놓고 **Commit changes**를 눌러 저장합니다.
3. 아래 주소에서 파일 이름만 실제로 올린 이미지 이름으로 바꿔 사용합니다.

```text
https://raw.githubusercontent.com/ponyochat/pic/main/파일이름.webp
```

예를 들어 저장소 첫 화면에 `sihyun-01.webp`를 올리면 이미지 주소는 다음과 같습니다.

```text
https://raw.githubusercontent.com/ponyochat/pic/main/sihyun-01.webp
```

위 이미지 이름은 예시이며, 아직 실제 이미지는 업로드하지 않았습니다.

- 파일 이름의 대소문자와 확장자까지 실제 파일과 같아야 합니다.
- 링크를 쓰기 편하게 영문 소문자, 숫자, 하이픈으로 파일 이름을 정하면 좋습니다.
- 하위 폴더에 올리면 주소에도 해당 폴더 이름을 포함합니다.
- 이 저장소에 올리는 파일은 누구나 볼 수 있으니 공개할 이미지만 올려주세요.
